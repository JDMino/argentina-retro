# Argentina Retro

Aplicación SPA para recorrer la historia y cultura popular argentina por décadas.

## Estructura
- /backend → API REST en NestJS
- /frontend → SPA en React + Vite

## Requisitos
- Node.js 20+
- PostgreSQL (local o Neon)

## Instalación
Ver instrucciones en backend/README.md y frontend/README.md
